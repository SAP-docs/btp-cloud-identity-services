# Onboarding and Provisioning

Onboard your users and groups into the Identity Directory to enable SAP Cloud Identity Services for secure authentication, authorization, and identity lifecycle management.

This section describes the available onboarding and provisioning scenarios and the corresponding configuration steps. It explains how to create and manage users and groups in the Identity Directory, configure centralized provisioning scenarios that use the Identity Directory as the central identity store, and automatically provision application-specific groups from the Identity Directory to target systems whenever changes occur.
