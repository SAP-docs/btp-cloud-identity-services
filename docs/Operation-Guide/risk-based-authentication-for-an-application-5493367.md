# Risk-Based Authentication for an Application

Use risk-based authentication to control user access to applications. Define authentication actions based on conditions like IP ranges, user groups, authentication methods, user types, email domains, and corporate attributes.

> ### Tip:  
> Risk-based authentication is often confused with conditional authentication.
> 
> -   Risk-based authentication configures the security level or authentication method you require users to use.
> -   Conditional authentication configures which identity provider authenticates your users.
> 
> Both use similar conditional criteria, such as IP ranges, groups, and user types. However, they serve different purposes in the authentication flow. Conditional authentication happens first to route users to the correct identity provider. Risk-based authentication then determines the security requirements after the identity provider is selected.
> 
> For more information about conditional authentication, see [Configure Conditional Authentication for an Application](configure-conditional-authentication-for-an-application-0143dce.md).
